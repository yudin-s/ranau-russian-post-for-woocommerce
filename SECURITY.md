# Security policy

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's **Security → Report a vulnerability** form in this repository. Include the affected plugin version, WordPress and WooCommerce versions, reproduction steps, impact, and any proposed mitigation. Do not include live credentials, customer data, or production exports.

Supported security fixes target the latest released version. A report is not considered resolved until the patched release artifact and its checksum are available.
